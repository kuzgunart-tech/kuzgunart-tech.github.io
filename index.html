Rclone Arsiv

Rclone Arsiv is a personal desktop archiving setup maintained by kuzgunart-tech. It uses rclone to copy selected files and folders from the owner's Mac to the owner's Google Drive.

Purpose

The setup helps archive files in Google Drive while allowing local copies to be removed after a successful upload. Transfers use a one-way copy operation.

Google account access

Google authorization is used by rclone on the owner's computer to access Google Drive. This website does not request Google sign-in or receive uploaded archive files.
