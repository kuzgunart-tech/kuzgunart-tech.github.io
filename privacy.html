Privacy Policy

Rclone Arsiv · Updated October 26, 2026

About this setup

Rclone Arsiv is a personal desktop archiving setup maintained by kuzgunart-tech. It uses rclone on the owner's computer to copy selected local files to the owner's Google Drive. It is not a public file storage service.

Google data accessed and used

With the owner's authorization, rclone accesses Google Drive file contents and metadata, including names, folder locations, sizes and modification times, to identify files and perform the requested archive transfers.

The Google Drive permission granted during setup allows reading and managing Drive files. The intended workflow uses one-way copying and does not propagate deletion of local source files to the cloud archive.

Storage and sharing

Archive transfers take place between the owner's computer and Google Drive. Rclone configuration and authorization tokens are stored on the owner's computer. This website does not receive or store those tokens or archived files.

Google user data is not sold, used for advertising, or used to train artificial intelligence models. This setup does not share archive contents with additional service providers. Google processes the uploaded data to provide Google Drive.

Retention and deletion

Archived files remain in Google Drive until the owner removes them or applies their own retention settings. The owner can delete archive files in Google Drive and remove local rclone configuration when it is no longer needed.

Revoking access

The owner can revoke this setup's authorization through their Google Account's third-party connections settings. Revoking access does not automatically delete archived files.

Website hosting

This informational website is hosted by GitHub Pages. GitHub may log visitor IP addresses for security purposes under the GitHub Privacy Statement .

Contact

Privacy questions can be submitted through the maintainer's GitHub issue tracker . Issues are public; do not include private files, passwords or authorization tokens.
